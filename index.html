ALEXANDRIA
Problem statement

How can a company let employees ask AI about internal knowledge without leaking data, without exposing what their role shouldn't see, and without trusting documents that may have been altered?

Support reps need approved answers fast Engineers need the raw technical detail Security and legal need nothing to leak
ALEXANDRIA
How it works

Every question passes two gates before the model sees anything.

1

Ask

Employee asks in the chat.

Next.js · Tailwind
2

Role filter

Your login decides which docs are even searchable.

FastAPI · JWT roles
3

Search

Find the closest permitted documents.

Vector search
4

Hash check

Recompute each source hash and compare it on chain.

SHA-256 · Solana Devnet
5

Answer

The model answers from verified sources only.

Claude today · local Llama 3 in prod
Security sits between retrieval and the prompt. Hidden or tampered documents never reach the model.
ALEXANDRIA
Cryptographic tamper detection

If a doc changes after approval, the answer says so.

1

Approve

A senior signs off. We hash the content with the author and time.

2

Anchor

The 32 byte hash goes to Solana Devnet. Not the text, just the hash.

3

Recompute

At answer time we hash the stored doc again and compare.

4

Flag

A mismatch drops the source and warns the user.
